# P2Line 线稿提取工具

## 主要功能

- **XDOG 线稿提取**：基于高斯差分算法，提供 Sigma、K、Tau、Phi、Epsilon 等参数调节，并支持去噪、断线连接和线条加粗。
- **PS 风格线稿提取**：模拟去色、反相、颜色减淡、最小值滤镜和色阶调整工作流。
- **点集提取与可视化**：XDOG 与 PS 模式均提供点集预览，支持扫描、路径追踪、轮廓三种旧版点序以及采样间隔与近点合并调节。旧版扁平坐标 JSON 格式保持不变。
- **线稿转有序笔画点集**：XDOG 与 PS 输出格式新增“有序笔画点集 JSON”。系统从最终线稿二值图重建中心线、分割笔画、简化与重采样，并优先规范开放笔画方向：主导竖向的笔画从上到下，主导横向的笔画从左到右，斜笔画优先从较高端开始；闭环保留追踪方向。随后在不反转单笔画的前提下，启发式缩短抬笔移动距离。预览中每条笔画使用独立颜色，绿色/红色分别标记起点与终点。该方向策略是通用线稿启发式，不代表能恢复真实书写笔顺。
- **笔画重建与点集可视化**：二值线稿 -> Zhang-Suen 骨架细化 -> 端点/分叉点检测 -> 最大链段追踪 -> RDP 几何简化 -> 等弧长重采样 -> 减少抬笔距离的路径排序。预览支持“线条 / 点集 / 叠加”三种渲染模式，点集模式为不同笔画使用不同颜色，并标记起点和终点；支持轨迹播放、参数调整、JSON 和 SVG 导出。
- **通用功能**：图片裁剪、反色、PNG/JPG/SVG/JSON 导出。

## 笔画重建说明

从图像重建的是**合理的几何轨迹**，并不能仅凭最终图片唯一还原真实的书写顺序。新模式会将骨架上的端点和分叉点作为链段边界，尽量保留分支，不在交汇点任意选择一个邻居吞掉其他路径；之后以贪心最近端点方式排序路径，减少抬笔空行程。该排序是启发式结果，不等同于原作者真实的落笔顺序。

复杂文字或密集线稿中的交叉、接触和噪声仍可能导致拓扑歧义。建议先通过阈值与短路径过滤去除噪声，再调节细化迭代上限、简化容差和重采样间隔。播放功能展示按路径顺序的逐步绘制；起笔/收笔效果目前为视觉演示，不是压力、速度或墨水扩散的物理仿真。

### 笔画 JSON 格式

```json
{
  "version": 2,
  "coordinateSystem": "crop-local",
  "ordering": "heuristic-minimum-pen-up-travel",
  "strokes": [
    [{ "x": 10, "y": 20 }, { "x": 12, "y": 21 }]
  ]
}
```

- `strokes` 是分段路径数组，每条路径内部按轨迹顺序排列。
- 坐标原点为图像左上角，单位为像素。
- `version` 用于后续格式演进；旧版扁平点集 JSON 不变。
- 路径之间代表抬笔/换笔，不代表真实作者必然在此处断笔。

## 快速开始

```bash
git clone https://github.com/luoy-oss/p2line.git
cd p2line
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 旧版点集数据格式

旧版“点集 JSON”仍然是扁平数组，例如：

```json
[
  { "x": 10, "y": 20 },
  { "x": 11, "y": 21 }
]
```

## 部署

项目使用 Vue 3 + Vite，可部署至 Vercel 或其他支持静态前端的服务。导出与图片处理均在浏览器本地完成。
